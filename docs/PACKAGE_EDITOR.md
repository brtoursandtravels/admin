# Package editor

Create packages through Basics, Content, Itinerary, Departures, Media, Policies and Publishing. Existing packages allow direct tab switching. Save as draft preserves unfinished content; publishing checks basic details, overview, public cover, complete itinerary, inclusions/exclusions and unfinished policy-template placeholders.

Content contains the information displayed on package details. There is no separate Summary field. Saving generates the API's short description from Overview (up to 500 characters) for sharing, related-package previews and the default SEO description. Custom SEO descriptions still take precedence; the full Overview is preserved.

- Slugs follow new titles until manually unlocked. Nights follow days until manually edited.
- Activities, highlights, inclusions and exclusions use reusable list controls. Lists support keyboard entry, confirmed removal and arrow/drag reordering.
- Destinations use a text area saved directly with the package, with one name per line for multiple destinations. There is no separate Add or Enter-to-confirm step. Categories display all options from the Categories master as single-select radio buttons, without a search field. Drafts may have no category; the form and API reject multiple categories. Existing packages with multiple categories must be explicitly reduced to one when edited; their saved data is not automatically changed.
- Category create/edit forms show Name, Status and Display order without URL slug or Description fields. The API generates unique category slugs automatically on creation. Renaming a category preserves its existing slug and stored description, so existing package-filter URLs continue working.
- The shared `FileUploader`/`MediaPicker` is used for package galleries, itinerary photos, PDF brochures, blog covers and destination covers. Upload from device and Choose from library have separate panels, shown side by side when space permits and stacked in narrow forms. Library selection supports server-side search and pagination. Selected IDs are fetched individually, so older files remain editable.
- Upload JPEG, PNG, WebP or AVIF images, or PDF brochures, up to 4 MB each. Single-file fields show their file card after selection; Edit allows replacement using the same upload/library panels. Replacement works at the selection limit, keeps gallery order and cover selection, and requires saving the entry. Upload progress and errors appear inside the edit dialog; a failed upload retains the current file for retry. Uploads are public by default. A replacement upload copies the entered alternative text, caption and visibility plus existing source/license notes; selecting a library replacement uses that asset's saved details. Save file details updates the current asset wherever it is reused.
- Removing a file detaches it from the form after confirmation. Save the package to persist removal. The library file is retained. Gallery arrows control order; Set as cover controls the public card and hero.
- The publishing checklist observes the selected cover across all tabs, so it stays correct during long editing sessions and updates when visibility or selection changes. Missing cover details are loaded automatically. A loading indicator and retryable error distinguish an unfinished lookup from a missing/private cover; only a public image completes this check.
- Itinerary photos, activities, meals and accommodation are stored in the API and rendered by the public timeline. Private photos are omitted from public responses.
- Fixed departures support optional prices and seat counts, plus Scheduled, Filling fast, Completed and Cancelled statuses. Enquiry-based trips have no fixed departures. Seat counts are staff-maintained, not automatic booking inventory.
- Policy templates contain editable placeholders and must be reviewed before publishing. SEO and live package previews reflect current form values; external search/social rendering can differ.

Run `npm run test:package-editor` for the isolated browser suite. It simulates API responses and never modifies production content.
